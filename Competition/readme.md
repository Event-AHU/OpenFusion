### 第四届世界科学智能大赛可控核聚变赛道：可控核聚变等离子体位形控制

[[主页](https://competition.ai4s.com.cn/race/12/introduction)] 


#### 赛题介绍
实现可控核聚变的核心挑战之一是对高温等离子体位形的精准控制。自DeepMind利用深度强化学习成功实现复杂的等离子体控制以来，利用人工智能技术解决等离子体控制难题迅速成为国际前沿研究的热点。本赛题顺应这一趋势，将在玄龙-50U装置（国际球形环参数领先）上展开深入探索。参赛者需基于该装置的高保真仿真环境设计人工智能控制策略，从基础位形控制起步，最终挑战复杂的先进偏滤器位形控制，在紧凑型聚变装置上书写人工智能驱动聚变控制的新篇章。


#### 背景知识
**1. 人工智能与核聚变**
人工智能（Artificial intelligence, AI）与可控核聚变正形成深度的共生关系。一方面，AI通过突破传统控制极限、挖掘物理规律和加速工程迭代，革命性地推动聚变研究；另一方面，聚变作为终极清洁能源，将彻底解决AI算力爆发带来的能源瓶颈。二者互为加速器，共同推动人类文明跃迁。

**2. 托卡马克位形控制**
等离子体位形控制是一个极具挑战性的高维、非线性、实时性要求极高（毫秒级响应）的控制场景，其核心目标是通过实时调节极向场线圈的电流，精确控制等离子体的位置、形状和等离子体电流，从而维持其稳定约束并避免与器壁发生破坏性相互作用。这一过程本质上是典型的多输入多输出（MIMO）反馈控制问题：控制器根据传感器实时测量的位形信息（如等离子体电流，中心位置，最外闭合磁面），通过比例-积分-微分（PID）控制或更先进的现代控制算法，计算并输出快速变化的电压指令，驱动电源系统调节线圈电流，以实现设定的控制目标。2022年，DeepMind 成功将深度强化学习应用于真实托卡马克装置的等离子体位形控制问题[1]，其技术框架如下图所示。

**3. EXL-50U装置**
玄龙-50U​[2]（EXL-50U）是新奥能源研究院建造的我国首座中等规模球形环聚变装置，其大半径0.6~0.8米、环向磁场1.2特斯拉、最大等离子体电流1兆安培等关键参数已达国际先进水平。EXL-50U配备一套中心螺线管（CS）线圈负责等离子体电流的击穿、爬升与维持；10套极向场（PF）线圈专司等离子体的位置与形状控制；此外还设有一套由上下线圈反向串联而成的快控线圈，用于快速抑制垂直位移不稳定性。在此平台上，新奥的智能研发团队已成功构建并验证了基于强化学习的等离子体位形实时智能控制系统​[3]，实现了对等离子体电流和位置的高精度控制，并已初步实现对等离子体形状的智能调控。

控制任务：针对每种位形，考核以下控制能力：

* 维持平衡：在给定初始平衡位形基础上，维持等离子体电流、位置和形状稳定不变。

* 变电流控制：跟踪随时间变化的电流目标（变化量≤100 kA），同时维持位置和形状不变。

* 变位置控制（仅偏滤器位形）：跟踪随时间变化的水平位置目标（变化量≤5 cm），同时维持电流、垂直位置、形状（最外闭合磁面相对于等离子体中心的相对位置）不变。
* 控制方式：智能体观测仿真环境状态（位形参数、磁诊断信号、线圈电流等），输出极向场线圈电压指令，控制频率1 kHz。

**仿真环境说明**
本赛题提供面向 EXL-50U 位形控制任务的高保真仿真环境。底层仿真器以 Docker 形式封装，选手在本地或评测环境中通过标准接口与仿真器交互，无需直接操作底层物理程序。环境采用回合式交互流程：

reset(seed, options)：开始一个新的 episode，并返回初始 observation
step(action)：输入当前步动作，返回下一步 observation
close()：关闭环境连接
其中，动作是 12 维真实物理电压。环境返回的 observation 为字典形式，核心关注以下量：

Ip：等离子体电流，标量
R、Z：等离子体中心位置，标量
lcfs_points：最外闭合磁面边界点序列，形状为 (32, 2)，表示32个顺时排列的边界点横、纵坐标
环境每一步还会返回当前时刻的目标 reference，便于直接做跟踪控制。辅助观测量如线圈电流、形状参数、磁诊断信号和磁通网格等，可帮助模型更好判断当前状态。详细说明见项目代码 docs/reference.md。环境支持两类任务模式：

hold：维持初始平衡状态不变
trajectory：跟踪给定的逐时刻 reference 轨迹
环境还提供 failure 状态标记：当 observation["failure"] = 1 时，可理解为等离子体破裂，对应本回合失败终止。达到最大步数 max_steps 则属于正常时间截断。reward 不由比赛固定规定，选手可根据训练目标自行设计。

官方当前提供 4 组预设环境配置，可通过 shot_id 选择。对大多数选手来说，可以先固定其中一个跑通训练，再逐步加入 reference 变化和 reset 扰动。

本地环境的安装方式、字段维度、配置项说明和示例代码，详见项目目录中的 README.md 与 docs/reference.md。

**评测指标**
初赛满分100分，从三个维度评估控制器在整个仿真时间段内的跟踪精度：

* 电流误差：等离子体电流Ip相对于目标的归一化绝对偏差（时间平均）。零分阈值：5%。

* 位置误差：等离子体中心位置与目标的欧氏距离（时间平均）。零分阈值：3 cm。
  
* 形状误差：等离子体边界形状与目标的偏差（时间平均）。零分阈值：3 cm。
  
* 各项误差通过线性评分函数映射为得分：误差为 0 得满分，达到零分阈值时得0分。各子任务得分还会乘以等离子体存活因子（存活时长/总时长），等离子体破裂将导致得分按比例缩减。分值分配：限制器位形共40分，偏滤器位形共60分。

具体评分公式与各子任务分值分配，参见《初赛评估标准》。复赛评测标准另行公布。

**任务提交**
本赛题采用 Docker 推理服务提交的方式。评测侧不会运行选手的训练脚本，而是启动选手提交的推理服务，并按约定接口发送 observation，请求服务返回当前步动作。

推荐的最小提交目录结构如下：

├── Dockerfile
├── inference.py
├── service.py
├── requirements.txt
└── model/
        └── policy.onnx
​
其中：

inference.py：选手主要实现推理逻辑的文件
service.py：对外提供评测调用接口的服务层
model/：存放最终推理模型文件
Dockerfile：用于构建评测镜像
提交服务需要满足以下基本要求：

能够在无人工干预条件下独立启动
能够正确处理新episode的reset
能够根据当前observation返回合法动作
输出动作为官方规定的12维真实物理电压
选手可以自由选择训练框架、特征工程和模型结构，但最终提交必须满足官方推理接口约束。若模型内部采用低维动作表示，也需要在提交服务中自行映射回官方12维动作空间。

评测时默认以 CPU 环境为主。提交内容不应依赖交互式界面、宿主机特定路径或训练阶段专用资源。若服务无法启动、接口不符合约定、输出维度非法或推理超时，将影响提交有效性与最终得分。

官方在项目中提供了标准submission模板和本地自测工具，便于选手在提交前完成镜像构建、服务健康检查和环境联调。提交目录结构、接口说明和自测方法详见submission/README.md与项目README.md。
